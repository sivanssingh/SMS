## 📖 About

The **School Management System** is designed to digitize and simplify school administration.

It provides separate functionality for:

- 👨‍💼 Administrators
- 👨‍🏫 Teachers
- 👨‍🎓 Students
- 👪 Parents
- 💰 Accountants
- 📚 Librarians
- 🚌 Transport Staff

The system brings academic, administrative, financial, and communication activities together in one platform.

# ⚙️ Installation

## 1. Clone Repository

```bash
git clone YOUR_REPOSITORY_URL
```

```bash
cd school-management-system
```

## 2. Configure Database

Create a MySQL database:

```text
school_management
```

Import the provided database file:

```text
database/school_management.sql
```

## 3. Configure Environment

Example:

```env
APP_NAME="School Management System"
APP_ENV=production
APP_DEBUG=false

DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=school_management
DB_USERNAME=your_username
DB_PASSWORD=your_password
```

## 4. Install Dependencies

For Laravel:

```bash
composer install
```

Then:

```bash
php artisan key:generate
```

```bash
php artisan migrate
```

Clear cache:

```bash
php artisan optimize:clear
```

# 🔒 Security

For production deployment:

- Use HTTPS
- Use strong passwords
- Protect `.env`
- Implement role-based permissions
- Validate uploaded documents
- Secure database credentials
- Restrict administrator access
- Keep regular database backups
- Keep dependencies updated

---

# 💾 Backup

Regular database backups are highly recommended.

```bash
mysqldump -u USERNAME -p DATABASE_NAME > school_backup.sql
```

Restore:

```bash
mysql -u USERNAME -p DATABASE_NAME < school_backup.sql
```
